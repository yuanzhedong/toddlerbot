Configs & code

⚙️
walk_class.gin
Scaled-down training budget (~30M timesteps, 2048 envs) for classroom runs that visibly improve in ~10–15 min. Use it: --gin-file "walk walk_class".
Viewing tip: for the demo videos and cross-file links to load reliably, serve this folder locally rather than opening files directly — python -m http.server 8000 -d docs/teaching, then open http://localhost:8000/. In VS Code / Antigravity, the Live Preview extension does the same. All pages are print-friendly (Ctrl/Cmd-P).

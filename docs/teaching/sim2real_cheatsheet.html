Sim-to-Real Loop — Cheat Sheet

ToddlerBot walk RL · from a trained policy to a robot that actually walks. Golden rule: measure the gap before you change anything.

Deploy: trained run → robot

  1. Output. Training writes results/<run>/model_best.onnx — that file is the 84→12 policy.
  2. Re-test the ONNX in sim (catch export bugs first): 
    run_policy.py --policy walk --sim mujoco --vis view
  3. Prep hardware: zero-calibrate motors (calibrate_zero.py), confirm a clean --policy stand, use the safety stand.
  4. Deploy + record: 
    run_policy.py --policy walk --sim real --record
    Inputs now = IMU + encoders; outputs drive motors @50 Hz.

Tips over under load / when movingMass / friction / inertia wrongmeasure (test_mass.py), fix MJCF, or widen DR
Every metric matches but still unstablePolicy overfit to sim quirkswiden domain randomization + retrain

Two knobs — always name which one

Make the sim match the robot (fixes bias). Calibration (per robot) + system ID. run_sysID.py (Optuna) fits motor torque / damping / friction on a single-motor bench rig, per motor type, once. No policy retrain.
Make the policy not care (fixes variance). Widen DomainRandConfig around the identified values, then retrain: 
add_push = True
friction_range = [0.3, 1.1]
kp_range = [0.8, 1.2]
You almost always need both. This loop is the research.
